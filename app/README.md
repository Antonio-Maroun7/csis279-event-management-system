# EventFlow – React frontend

React 19 + Vite + React Router frontend of EventFlow.

Setup, environment variables, running instructions and the full project documentation are in the [root README](../README.md).

Quick start (the API must be running):

```bash
cp .env.example .env   # Windows: copy .env.example .env
npm install
npm run dev            # http://localhost:5173
```

Other scripts: `npm run build` (production build) and `npm run lint` (Oxlint).
